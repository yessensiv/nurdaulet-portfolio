# Nurdaulet Yessensary — Portfolio

Самостоятельный сайт на HTML, CSS и JavaScript, перенесённый по дизайну Majd из Framer. Для работы Framer и установка библиотек не нужны.

## Запуск

Нужен Node.js. В папке проекта выполните:

```text
npm run dev
```

Откройте http://localhost:4173. Проверка синтаксиса: `npm run check`.

## Персонализация

Все основные данные находятся в `dist/content.js`: имя, варианты заголовка, описание, услуги, проекты, почта и соцсети. Для фото добавьте файл в `dist/assets` и укажите его путь в `portrait`.

Добавлены реальные проекты из GitHub: ENT Math, DentaLux, DocMind и Flow. У DentaLux используется исходная фотография проекта, остальные карточки имеют графические обложки. Это обложки проектов, а не скриншоты интерфейсов. Аватар, контакты и описание специализации взяты из профиля `yessensiv`. Фото автора шаблона и его отзывы не используются.

Контактная форма открывает почтовое приложение с подготовленным письмом на адрес из GitHub-профиля. Письмо нужно отправить в почтовом приложении. Серверной отправки нет.

## Структура

- `dist/index.html` — оболочка сайта.
- `dist/style.css` — исходная визуальная система и адаптивные размеры.
- `dist/app.js` — страницы, меню, смена профессий, анимации и форма.
- `dist/content.js` — данные портфолио.
- `dist/assets/` — локальные шрифты, текстура, звёзды, изображения.
- `scripts/serve.mjs` — локальный просмотр без зависимостей.

Доступны главная, `/work`, `/work/project-01` и остальные страницы проектов. Перед размещением выполните `npm run build`: команда создаёт отдельные HTML-файлы маршрутов. Для хостинга загрузите `dist`. При добавлении новых проектов повторите эту команду.

Анимацию можно приостановить кнопкой у заголовка. Сайт учитывает системную настройку уменьшения движения. Меню работает с клавиатуры и закрывается по Escape.

Источник дизайна: https://majd-portfolio.framer.website/ и пользовательская копия шаблона. Данные проектов: https://github.com/yessensiv. Иконка Flow взята из `flow-downloader/docs/flow-icon.svg`, фотография DentaLux — из `dentalux/public/images/clinic/interior.jpg`. При дальнейшем использовании сохраните применимые условия лицензии оригинальных ресурсов.
